# 项目机会推介微信文字

把一份项目材料（BP 文件、尽调画像、用户粘贴的项目要点）压缩成一条微信可直发的推介文字。收信人 30 秒内读完，产生"想约路演 / 想要 BP"的兴趣。

这是**转发推介**，不是尽调或汇报：保留材料原文的定位语和卖点口径，让项目方最强的说法站到台前；事实纪律靠"不编造、不加码"守住（见规则）。

## 固定格式模板

严格按以下顺序成文。材料缺料的段整段省略，不编造。

```
【公司名】
—— 一句话定位：定义赛道身份 + 终局愿景，并点出最快落地的场景

【定位】（可带一句定位宣言，如"打造XX时代的XX基座"）
* 亮点一：行业唯一/首家/稀缺 + 已完成验证的事；
* 亮点二：同上。最多三条，每条一行。

【顶尖XX团队】（小节标题可带定语，点出团队成色）
学术背景 + 产业背景来源列举（名校系+大厂/同业名单），收尾一个定性比喻（如"XX特种部队"）。

【技术优势】（非技术公司改为【产品与壁垒】）
一句趋势判断作引言，随后 1–4 个编号点，每点格式：
N."标签"— 模块名/产品代号：能力一、能力二，指标或验证结果。

【商业化进展】
赛道定位语（全球唯一/行业稀缺）+ 材料里最硬的事实：标杆客户、POC/ROI 验证、订单、服务客户数。

【历史股东】
财投 + 战投 + 产业方名单，顿号分隔，收尾"等头部财投及战投"式概括。

【本轮融资与估值】
轮次、拟融金额、投前/投后估值、领投方或老股东追加安排。

【交割时间安排】
TS/增资协议签署、打款交割的时间计划；有额度窗口或截止日期的必须写明。
```

估值与交割两段是收信人的行动依据，区别于其他段：材料有则必写；材料缺则成文前先向用户要一次，仍没有的在文末标"估值及交割安排待补充"，不留空、不编数。

## 写作规则

1. **纯文本**：微信不渲染 markdown。禁止 #、**、表格、链接语法。小节标题用【】，条目用 * 或数字。
2. **沿用原口径**：定位语（"行业唯一""全球最大"等）按材料原文保留，可删不可加码；不得自行发明更高程度的形容。材料没写的事实一律不写。
3. **空格代替加粗**：需要强调处用空格断词（如"行业 唯一实现 0真机数据 构建"），这是微信转发文的惯用强调法。
4. **不放个人信息**：联系人手机号、邮箱、微信号不入文；需要时结尾加一句"BP 及联系方式可索取"。
5. **密度与篇幅**：全文 300–700 字；每句承载一个事实或一个定位；删掉不带信息量的套话。
6. **顺序不可换**：读者按"是谁→凭什么→做到哪→谁在押注→怎么参与"的顺序读，段落顺序服务这个逻辑。
7. **估值与交割是行动段**：投前估值 + 融资额 = 投后估值，口径不可混写；未定事项标"待定，以最终交易文件为准"，不为了行文顺而拍死一个数。

## 工作流程

1. 读材料：本地 BP/文档用 local-markitdown 转 Markdown；用户粘贴文字直接用。
2. 动笔前先列要素表：公司名 / 一句话定位 / 亮点 2–3 条 / 团队构成 / 技术或产品模块 / 商业化最硬事实 / 股东名单 / 轮次与估值（轮次、金额、投前投后）/ 交割时间节点。
3. 按模板成文，自检：无 markdown 残留、无个人信息、无编造或加码、缺料段已省略、估值与交割两段已填实或标注待补充、字数达标。
4. 交付：成文放进一个纯文本代码块方便整段复制；代码块外用一句话提示"可整段复制发送，如需低调版或补充轮次信息可再调"。

低调版（用户要求时）：把绝对化定位语软化为"公司称行业唯一"或直接删去，保留事实与数字，团队与股东段保持原名。

## 黄金样例（口径与节奏对齐此例）

```
【光象科技】
—— 定义 下一代物理原生智能体，加速实现具身AGI，并最快落地汽车产线等工业场景

【定位】打造Physical AI时代的 物理原生基座模型 和 具身超级终端
*行业 唯一实现 0真机数据 构建物理原生智能 并 完成大规模场景验证；
*行业 唯一真正通过多家汽车头部主机厂POC及ROI验证 并 商业闭环 的具身公司。

【顶尖智驾及机器人团队】
清华系顶尖科学家+阿里、腾讯、华为、百度、蔚来、极智嘉等全球科技巨头的产业化精英，顶尖学术+产业方阵容 构建 "具身智能特种部队"。

【技术优势】
具身智能的下一次跃迁，是物理智能涌现。光象打造物理原生智能生成体系。
1."大脑"— 物理原生世界行为模型（Phi-World）：模型具备物理智能泛化能力、物理因果推理能力；
2."算法"— 全球Top强化学习矩阵（Phi-RL Matrix）：以"机器人自我学习方式"实现从"模仿"到"超越"，泛化表现、操作精度、任务成功率行业领先；
3."数据资产"— 百万级场景数据+千亿级物理交互数据的物理数据资产（Phi-Space）：构建全球最大高保真、可并行、生成式、可扩增的工业物理数据资产体系，行业稀缺已实现0真机数据zero-shot部署；
4."具身平台"— 独创具身智能平台（Phi-Arch）：通过 独创具身智能开发平台GOPS 实现能力闭环，已服务300多家工业客户，构建 持续进化与低成本规模化部署 体系。

【商业化进展】
具身赛道 全球唯一 与数家头部汽车主机厂深度合作，汽车主机厂制造产线POC及ROI验证通过，行业稀缺获得汽车制造产线订单的具身智能公司。

【历史股东】
IDG资本、东方富海、01VC、埃夫特、清华大学等头部财投及战投。
```

样例未含估值与交割两段（原始转发即无）；实际产出必带这两段——材料有则填实，无则标"待补充"并提示用户补料。
