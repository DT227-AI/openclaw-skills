# 研究执行与图表表达

完整行业研究时参考本文件；局部更新只执行相关部分。

## 1. 由研究问题确定深度

以技术机制解释产业判断，但不写成百科全书。技术段落至少服务于性能差异、工程成本、可扩展性、商业化条件或壁垒中的一项。对读者不熟悉的概念先给短定义，随后说明它为什么影响判断。

从问题倒推资料需求，例如：

- “扩展后控制系统成为瓶颈”需要系统结构、控制接口数、误差/热负荷等证据。
- “某部件先商业化”需要采购项目、单机用量、外购比例、竞争供应与验收数据。
- “某路线有客户价值”需要完整任务基线、同规模结果、部署成本及客户采用证据。

## 2. 解析参考资料

若给出样本报告，记录实际页数、目录、章节边界、图表编号、页码偏移与文档版本。文本抽取后检查图片表、图谱、脚注和来源；对决定框架或结论的图表回看页面。OCR 不确定的数字不可直接当作证据。

拆成三类内容：

1. 可迁移方法：论证顺序、比较维度、案例写法、图表功能。
2. 行业特定知识：术语、机制、指标，使用时按专业来源复核。
3. 时点事实或判断：产品、公司、融资、纪录、预测，重新研究时独立核验。

模仿报告结构不意味着复制其结论。样本信息有矛盾时回到原始材料，仍无法解决就注明范围与缺口。

## 3. 从单元到系统再到经济性

以“基本单元 → 子系统 → 完整系统 → 客户工作流”四层核查。某项器件纪录只支持该层结论；跨层推断需要说明接口、资源开销、损耗、控制和可靠性等桥接条件。

对每条路线询问：

- 规模扩大时哪些变量线性增长，哪些可能更快增长？有模型还是仅定性推测？
- 最佳结果是否同时成立，还是不同条件下分别得到？
- 解决一种瓶颈是否引入新的制造、能耗、计算、维护或供应链约束？
- 关键输入由公司自研、外购还是依赖科研设施？能否稳定复现和交付？
- 用户需要的最终结果，是否受本路线指标以外的环节限制？

在新行业重建专业指标。对半导体设备可能是产能、良率、缺陷与套刻，对机器人可能是成功率、节拍和工况，对能源设备可能是净输出、可用率与寿命；这些只是选指标示意，不是各行业完整标准。

## 4. 应用和公司同步验证

先用客户任务而非公司宣传定义应用。混合系统要拆清贡献，不能用全工作流的输入规模冒充新技术独立处理的规模。分别问：新技术是否可行？是否比合适基线更好？是否值得客户付费？

公司名单从路线及产业链生成，再根据产品归属、进展和客户证据筛选。科研声誉、融资热度、政策支持可作为线索，但不能代替系统性能、IP 权利和交付能力。

## 5. 从产业约束推导投资判断

形成可追溯链：

`任务需求 → 替代方案缺口 → 技术条件 → 工程瓶颈 → 产品/供应环节 → 采购与验收 → 可实现收入 → 投资动作及失效条件`

只写证据能覆盖的长度。若仅有研发需求，说明收入验证还缺采购和验收；若缺价格、成本和现金流，不包装成完整估值意见。

用户要求市场预测时，分科研、示范和商业客户，按应用/产品拆算，保留情景假设与重叠抵消。用户要求估值时区分已验证业务与里程碑依赖业务，选与阶段相称的方法。

## 6. 写作与图表

正文先完成路线、应用及公司表，再写论证，最后写摘要。原报告可借鉴的图表功能如下：

| 图表 | 作用 | 必须解释的内容 |
|---|---|---|
| 原理/系统流程图 | 连接抽象机制与真实装置 | 输入、输出、控制、测量/检验及辅助系统 |
| 路线机制图 | 显示差异产生在哪里 | 载体、接口、关键材料/器件与环境 |
| 路线比较矩阵 | 提供横向判断 | 指标定义、版本、条件与不可比边界 |
| 研发路线图 | 描述进度与依赖 | 已实现和规划节点采用不同标记 |
| 瓶颈与解法表 | 找到可能改变格局的变量 | 原因、候选解法、证据、代价、里程碑 |
| 应用案例表 | 连接技术结果与使用价值 | 任务、规模、基线、贡献和付费证据 |
| 产业链图谱 | 连接路线、部件与企业 | 专属/共用环节、接口、供给和替代关系 |
| 公司进展表 | 建立可跟踪的管线 | 身份、产品、指标、客户证据、下一步 |

只采用能帮助判断的图表。不要以配图数量、页数或固定图表数当作完成标准。科学曲线注明坐标、条件和数据来源；没有数据不得绘制仿真式曲线冒充实测。路线图中企业宣称的未来节点不得画成已完成。

## 7. 更新与交付检查

更新报告时先确定哪些新证据改变了路线/阶段/应用判断，再改关联矩阵、正文和摘要。保留冲突来源与时间，不静默覆盖历史披露。

交付前做四项实质检查：

- 推导检查：每个投资方向可回溯到技术/需求证据，列明未验证跳跃。
- 可比检查：同一对象、版本、单位、条件和日期；不可比项明确标注。
- 商业检查：科研活动、订单、交付、收入与回款没有混用。
- 一致性检查：摘要、路线矩阵、案例结论和公司表不相互矛盾。

缺证时保留有边界的成果及待验证项，不补写数字或用宏观前景掩盖缺口。
